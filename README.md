# YS CART Blocksy 整合

在 **Blocksy 佈景主題**（免費版即可）的頁首建構器（外觀 → 自訂 → 頁首）提供 YS CART 專屬元件，拖放即用：

目前版本：**1.2.3**

| 元件 | 說明 |
|------|------|
| **YS 帳號** | 帳號圖示。未登入連到 YS CART 登入頁、登入後連到會員中心（兩者皆可改為自訂連結），可選顯示文字標籤。 |
| **YS 商品搜尋** | 搜尋圖示，點擊開啟 YS CART 全屏商品即時搜尋。 |
| **YS 搜尋框** | 行內商品搜尋框，輸入即時顯示商品結果；四段寬度（窄／中／寬／填滿）。 |
| **YS Cart** | 購物車圖示＋數量 badge。點擊行為可選 **開啟迷你購物車**（預設；右側抽屜，品項／移除／小計／前往結帳，加入購物車後自動開啟；modal dialog：背景 inert、Tab 焦點圈、Esc／遮罩關閉、焦點回到開啟它的元素）或前往購物車頁。結帳頁（核心隱藏迷你購物車）點擊直接前往購物車頁。搭配核心「右下角浮動購物車」關閉，購物車入口就只在頁首。 |

## 需求

- WordPress 6.0+、PHP 8.2+
- [Blocksy](https://creativethemes.com/blocksy/) 佈景主題（免費版即可，支援 child theme）
- YS CART 外掛（「YS 商品搜尋」「YS 搜尋框」需啟用核心「商品即時搜尋」功能：商店設定 → 功能模組）
- 迷你購物車 drawer 需 **YS CART ≥ 2.58.2**（`YS_CART_BLOCKSY_DRAWER_MIN_CORE`）；舊核心的購物車元件自動退回「前往購物車頁」

## 使用方式

1. 啟用本外掛（缺 Blocksy 或 YS CART 時不會生效，外掛頁會提示）。
2. 前往 **外觀 → 自訂 → 頁首**，在元件清單中找到「YS 帳號 / YS 商品搜尋 / YS 搜尋框 / YS Cart」。
3. 拖入任一列（上排／主列／下排），右側面板調整選項，發佈。

## 設計原則

- **零後台頁面、零 REST、零 AJAX、零資料表** — 所有設定都在 Customizer 走 Blocksy 原生選項系統。
- 元件是核心功能的薄包裝：搜尋走 YS CART 既有即時搜尋（前端資產與 API 由核心提供），帳號連結走核心頁面解析，
  迷你購物車 drawer 用的是核心同一份樣板／JS／REST（本外掛只負責開關與抽屜樣式）。
- 圖示顏色 `currentColor` 跟隨 Blocksy 頁首文字顏色（透明／置頂頁首自動適配）。
- Fail-soft：相依不在時前台不輸出任何標記、不產生錯誤。
